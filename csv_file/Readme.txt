==========================================
RealFI CSV Data Directory - README
==========================================

This folder contains all intermediate and final CSV files used in the
Feature Sensitivity Score (FSS) computation, incremental instruction statistics
generation, and correlation/stability analysis for RealFI.

Each file is described below.


------------------------------------------
1. stat.csv
------------------------------------------
• Raw instruction-level statistics generated by the profiler.
• Contains cumulative values for:
    - Execution_Count
    - Avg_Latency
    - Opcode, Bitwidth
    - Memory level and branch info
• Used as the input for incremental processing.


------------------------------------------
2. stat_incremental.csv
------------------------------------------
• Processed version of stat.csv where cumulative counts and latencies
  are converted into per-sample incremental values.
• Ensures each row represents an independent instruction snapshot.
• Used as input for FSS computation.


------------------------------------------
3. stat_FSS_Score.csv
------------------------------------------
• FSS scores computed directly from the cumulative stat.csv
  (before fixing the cumulative-value issue).
• Kept for reference; NOT used in the final evaluation or stability analysis.


------------------------------------------
4. stat_incremental_FSS_Score.csv
------------------------------------------
• Final FSS results computed from stat_incremental.csv.
• Includes:
    - Normalized feature columns
    - Weighted FSS scores
• This is the main dataset used for:
    - Weight sensitivity analysis
    - Stability evaluation
    - Correlation analysis


------------------------------------------
5. stat_incremental_FSS_Score_pearson_corr.csv
------------------------------------------
• Pearson correlation matrix between the four normalized FSS features:
    - Opcode_Num_Norm
    - Bitwidth_Norm
    - Execution_Count_Norm
    - Avg_Latency_Norm
• All correlations are below 0.3, indicating weak linear dependence.


------------------------------------------
6. stat_incremental_FSS_Score_spearman_corr.csv
------------------------------------------
• Spearman rank correlation matrix for the same four features.
• Values remain below 0.3, confirming weak monotonic dependence.
• Used to support the independence and complementarity of the FSS features.


------------------------------------------
Summary
------------------------------------------
Files in this directory form a complete workflow:
    stat.csv
        → stat_incremental.csv
        → stat_incremental_FSS_Score.csv
        → stability analysis & correlation analysis

The FSS-related analysis should always be based on:
    stat_incremental_FSS_Score.csv

Older or cumulative-score versions are kept only for completeness and comparison.
